# minipoa -W 500 SP 下降 / 默认参数高内存：诊断结论（2026-10-14）

## 背景
- 现象：mtb_benchmark 超长高相似序列（342 条，250 kbp / 500 kbp / 1 Mbp）上，`-S -W 500` 的 Scaled SP 比默认参数低；默认参数（min_w=20000）则耗时长、内存大。
- 本轮只做诊断，不改仓库代码。基线为本地 v1.4.3（HEAD 550692b），在服务器上重新编译。
- 实验目录（服务器 `MSA_Dedicated_Server_Remote`）：`/mnt/sda/liuhaodong/workspace/experiment/minipoa/tmp/`
  - `patches/`：diag（`MINIPOA_DIAG=1` 时输出锚点/分段日志）、chainfix（`is_equal=true`）、noresize（删掉 `score.resize`）
  - `scripts/`：`run_all.sh`（运行矩阵）；`analyze.py` / `cols.py` / `private_cols.py`（列构成）；`locus_diff.py` / `block_show.py` / `block_period.py`（逐位点）；`stack_check.py` / `locus_check.py`（单点核查）；`analyze_all.sh`
  - `results/<ds>/`：各 run 的 `.msa`、`.time.log`、`.sp.txt`、`.diag.tsv.gz`；分析结果在 `results/<ds>/analysis/`

## 结论

### 1. Scaled SP 的下降由两部分组成
| | 原始 SP 变化 | 列数变化 | Scaled 变化 |
|---|---|---|---|
| 250kbp | −0.009% | 332761 → 335989（+1.0%） | −0.97% |
| 500kbp | −0.10% | 610197 → 627121（+2.8%） | −2.80% |
| 1Mbp | −0.05% | 1146132 → 1173209（+2.4%） | −2.36% |

列数增加是 Scaled SP 下降的大头。

### 2. 逐位点比较（`analysis/locus_R2_vs_R1.txt`、`analysis/block_period_all.txt`）
- 方法：同步列定义为在两个 MSA 中都无 gap、且每条序列碱基序号一致的列；相邻同步列之间为一个区块。同一区块在两个 MSA 中含有相同的碱基，原始 SP 可以直接比较，所有区块之和等于总 SP。不同的区块很少：250kbp 10 个，500kbp 25 个，1Mbp 58 个。
- 区块分类：取区块中最长的序列，计算最佳周期的自相似度（随机背景约 0.30）。

| 类别 | 1Mbp dSP / dCols | 500kbp dSP / dCols | 250kbp dSP / dCols |
|---|---|---|---|
| 9 bp 周期重复阵列（0.45≤sim<0.85） | **−5728 万** / +8744 | **−4122 万** / +9492 | — |
| 完美串联重复（sim≥0.85） | +412 万 / +1177 | −273 万 / +160 | −93 万 / +280 |
| 大插入（非重复） | **+2346 万** / +17463 | **+1356 万** / +7575 | −29 万 / +2948 |
| 其它 | +96 万 / −307 | +91 万 / −303 | −0.1 万 / 0 |
| 合计 | −2873 万 / +27077 | −2949 万 / +16924 | −123 万 / +3228 |

（dSP = W500 − 默认，负数表示默认参数更好）

### 3. W=500 的真实缺陷：锚点落在串联重复内部
- 机制：在串联重复阵列中，一个 19-mer 可以按相差整数个重复单元的多条对角线匹配到共识上。被选锚点取哪一条有偶然性，却把 indel 钉在了锚点的一侧。各序列的锚点位置不同，同一个 indel 就被放到了不同的列。
- 小例子（250kbp 参考坐标 24353，18 bp 重复单元）：219 条序列删除了一个重复单元。默认参数全部左放；W=500 有 34 条因为锚点（q 24361 到 24379，diag=0）落在重复内部而右放。区块 SP 从 763152 降到 188144。
- 主导位点（参考坐标 333248，约 5.5 kb，9 bp 周期重复）：156 条序列多出 2.6 到 3.1 kb（拷贝数各不相同）。区块内 W=500 锚点中有 44% 是重复 minimizer；同一共识位置上的锚点，相对侧翼的偏移成组地相差 9 bp（1185/1176、1700/1691）。区块 SP：默认 68.1M，W=500 19.0M（1Mbp −4909 万）。
- 默认参数的锚点间距约 2 万 bp，很少落进这类区域，所以 POA 能在整段内自由放置 indel。完美串联重复上两种参数都有偶然性（1Mbp 上 W=500 更好的 7 个，默认更好的 9 个），但 W=500 碰到的次数更多。

### 4. 大插入位点上 W=500 反而更好（列更多）
- 机制：两条序列在相距几百 bp 的不同位点插入了 IS6110。默认参数的段很长，会把两份 IS 叠在一起，代价是错开其中一组的直系同源侧翼。W=500 的锚点把两个位点隔开，两份 IS 各占一组列。
- 例子（500kbp，参考约 482.6k 与 483.2k）：默认参数让 23 条序列约 600 bp 的侧翼与其余约 318 条错位；W=500 侧翼全部对齐。局部 SP：默认 115114351 / 6331 列，W=500 124630415 / 6296 列。
- 整体上，这一类的原始 SP 是 W=500 更好（1Mbp +2346 万），但多出的列（1Mbp +17463）拉低了 Scaled SP。按位置同源判断，W=500 的结果是对的，Scaled SP 的惩罚是指标本身的特性。

### 5. 反事实：只修重复区
同步列在两个 MSA 中完全一致，所以把重复类区块换成默认参数的排法，得到的仍是合法 MSA，下面的数是精确计算：
| | 默认 | W=500 | W=500 + 重复区用默认排法 |
|---|---|---|---|
| 250kbp | 0.7220 | 0.7150 | 0.7156 |
| 500kbp | 0.7927 | 0.7705 | 0.7838（原始 SP 比默认 +0.051%） |
| 1Mbp | 0.8503 | 0.8303 | 0.8381（原始 SP 比默认 +0.043%） |

只修好重复区，W=500 的原始 SP 就能超过默认参数。剩余的 Scaled SP 差距来自插入位点的列数。

### 6. 排除的候选
- 链化 `is_equal=false`（lchain.cpp:30）：R4/R5 没有改善。排除。
- 带宽模式：R3 只回升 0.0005 到 0.0016。排除。
- `score.resize(node.size())`（align.cpp:70）：R6 输出不变，耗时差异在噪声范围内。排除。

### 7. 默认参数的内存和时间来源（已确认）
- R1 中 100% 的段走自适应带，平均段长 m≈2 万，最长 5.3 万。
- 分配单元数 / 实际计算单元数：250kbp 7.6 倍，500kbp 11.0 倍，1Mbp 12.8 倍。单段最大分配 15.6 GB。原因是自适应带按 n×m 全矩阵分配（align.cpp:98-115），而内存池首次按 2 倍申请且只增不减（mem_alloc_utils.h）。缓冲区在段之间复用，页面一直驻留。16 个线程合计，1Mbp 峰值约 108 GB。
- DP 总耗时（各线程累加）：1Mbp 默认 1512 s，W=500 为 214 s。

## 未解决问题
- 区块分类用的是单条最长序列的自相似度阈值（0.45/0.85），是粗分类；"9 bp 周期重复阵列"对应哪些基因（是否为 PE_PGRS）未做注释核实。
- 完美串联重复上，两种参数都有不一致放置的情况，说明非锚点因素（POA 回溯偏好、加入顺序）也有影响，未细查。
- 诊断补丁中 `DIAG_P` 的格式串少一个 `%d`：前 10 列正确，最后一列 `node.size` 丢失。下次使用前应修正。

## 下一步（需决定方向）
1. **修 W=500 的重复区缺陷**（收益最明确）：选锚点时避开串联重复或低复杂度区域。可选做法：
   - a. 跳过重复 minimizer 锚点（共识或 query 中出现次数大于 1），改用下一个合格锚点；
   - b. 检测锚点附近的周期性（如 k-mer 自相似），落在重复阵列里就整体跳过该区域，让段延伸到重复区之外。
   预期：Scaled SP 1Mbp 约回到 0.838，原始 SP 超过默认参数。验证方式：重跑 R2，对比区块 333248、24353 等。
2. **评价口径**：插入位点多出的列是位置同源意义下的正确结果。论文中建议同时报告原始 SP，并说明 Scaled SP 对列数敏感。
3. **默认参数高内存**（独立问题）：自适应带改为按带宽分配，或给内存池加回收。
